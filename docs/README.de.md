# Dokumentation

Die Anleitungen für Benutzerinnen und Benutzer gibt es auf Deutsch und Englisch;
die Dokumente für Entwickler und die ausführlichen Anleitungen im Bereich
"Sandbox" nur auf Englisch. Oben im Seitenkopf wechselst du die Sprache.

## Benutzerhandbuch

Für alle, die die O365 Tools benutzen.

| Anleitung | Lies sie, wenn ... |
|---|---|
| [Die O365 Tools im Überblick](user/tools.md) | du wissen willst, welches Tool was tut und wie du es startest |
| [Sprache](user/language.md) | du die O365 Tools auf Englisch oder Deutsch möchtest |

## Entwicklerdokumentation

Für alle, die die O365 Tools ändern. Nur auf Englisch.

| Dokument | Lies es, wenn ... |
|---|---|
| [Mehrsprachigkeit (Design)](dev/multilanguage.md) | du eine Meldung, einen Befehl oder eine Sprache hinzufügst |

## Sandbox

unverändert und auf Englisch, bis sie aufgeräumt und ins Benutzerhandbuch oder in
die Entwicklerdokumentation verschoben werden.

| Anleitung | Worum es geht |
|---|---|
| [Erste Schritte](sandbox/getting-started.md) | Die häufigsten Abläufe von A bis Z |

| [Prüfregeln](sandbox/health-rules.md) | Was jede `RuleId` bedeutet |
| [Dokumentsätze](sandbox/document-sets.md) | Metadaten, die auseinandergelaufen sind |
| [Drucken](sandbox/printing.md) | Eine Liste als geprüftes PDF |
| [Migration](sandbox/migration.md) | Was aus den alten Skripten geworden ist |
